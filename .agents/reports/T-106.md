## Behavior
- Public deployment creation returns 400 for malformed/unsafe payloads; payloads omitting `private` are still accepted, persist as `private: true` with `secretKey: null`, and keep the 200 response shape.
- Explicit `private: true` without `secretKey` is still rejected; explicit `private: false` remains a valid public deployment.
- `api_key` in the public execution query string no longer authenticates a private deployment; `X-Neuron-Key` remains required and unchanged.
- Webhook credential-like fields are removed from `webhookData` before execution and logging.
- `/api/v1/execute/workflow` is rate limited to 60 requests/minute/client in memory; successful responses carry no rate-limit headers, and the 61st request returns 429 `{error:"Too many execution requests. Please wait a moment."}`.
- HTTP node requests reject non-http(s) schemes and any target resolving to private/loopback/link-local/reserved addresses; the initial connection and every redirect hop are pinned to validated public IPs via a per-hop undici dispatcher, preventing DNS-rebinding TOCTOU. Original hostname is preserved for Host/SNI/certificate verification, and method/body follow native fetch semantics.
- No response shape/status, terminal response projector, retry schedule, realtime channel/event string, Dexie draft identity, T-104 user scoping, or T-105 redaction/fail-fast behavior was changed.

## Risks and limitations
- DNS-rebinding TOCTOU — closed. `resolvePublicHttpTarget` returns validated addresses and `createPinnedDispatcher` forces connect lookup to those addresses for the initial request and every redirect hop; the original hostname remains the TLS SNI/certificate name. Security disposition awaits post-fix sign-off.
- Rate limiter uses the default in-memory store — accepted residual for this single-process hardening scope; the 60/minute limit is per API process, not shared across multiple instances. A shared store is required for a global limit.
- Credential filtering is name-based — opaque values without credential-like key names are not inspected; callers must not place secrets in benignly named fields.
- Prettier check failure — the repository is not Prettier-clean at baseline; this task preserved existing style instead of reformatting leased files wholesale.
