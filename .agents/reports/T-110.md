## Risks and limitations

- The stale `pnpm-lock.yaml` importer entry for `packages/runtime → @neuron/db` was removed by the T-103a lockfile owner after the runtime manifest change; frozen lockfile verification passed.
- Ports are exported through the `@neuron/shared` root barrel rather than a dedicated subpath; adding an export path requires `packages/shared/package.json`, outside this lease.
- `ExecuteWorkflowType` keeps collaborators optional and uses optional chaining; a direct caller that omits them gets no realtime/vault/variable effects. Every in-repo production caller injects the defaults, and the ADR specifies optional collaborators for incremental adoption.
- Runtime graph types are minimal structural shapes rather than shared domain node types because the out-of-lease controllers pass DB rows (`positionX/Y`); an explicit row→domain mapper belongs with T-112 orchestration consolidation.
- `pnpm lint` only runs for `packages/ui` and `frontend` (no backend/shared ESLint script exists); new adapter/runtime files were not ESLint-checked by the declared command.
