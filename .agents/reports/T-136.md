## Proposal and approval
- scope: make the backend production build resolvable by keeping the `isolated-vm` native addon outside the esbuild/tsup bundle and declaring it as a runtime dependency of `backend`.
- options considered:
  - (a) rebuild the addon in place and keep bundling — tried before this task (`pnpm rebuild isolated-vm` exit 0, recorded at `.agents/ledger.yaml:662`); rejected because the bundler still tried to inline `./out/isolated_vm`, so the build remained broken.
  - (b) upgrade to `isolated-vm` 6/7 — rejected due to Node compatibility (`.agents/ledger.yaml:664`); no version change made.
  - (c) externalize `isolated-vm` in tsup and declare the exact version in `backend` — chosen; smallest change, preserves T-103a sandbox behavior and the pinned version.
- approval: explicit foundation lease granted by coordinator at `.agents/ledger.yaml:661` and `.agents/ownership.yaml:31`. This continuation pass was bounded to `.agents/reports/T-136.md` plus confirmation that the applied config remains intact; no source/config edit was made.
- external-doc basis: official tsup README (https://raw.githubusercontent.com/egoist/tsup/main/README.md) lists bundleable inputs as `.js`, `.json`, `.mjs`, `.ts`, `.tsx` — native `.node` addons are not among them. The `external` shape was verified by the successful scoped build below, not adopted from memory alone. No new external tool or dependency was introduced.

## Root cause
- `.agents/reports/T-122.md:40` recorded the pre-fix failure: `pnpm build` exit 1 with only `backend#build` failing — `✘ [ERROR] Could not resolve "./out/isolated_vm"` from `node_modules/.pnpm/isolated-vm@5.0.4/node_modules/isolated-vm/isolated-vm.js:1:25`.
- `tsup` (8.5.1) delegates bundling to esbuild, which cannot inline the native `.node` addon shipped by `isolated-vm@5.0.4`. Rebuilding the addon fixes the on-disk artifact but does not change what the bundler attempts to resolve.
- `backend` did not declare `isolated-vm` itself, so an externalized import would not be guaranteed to resolve from the deployed package. The fix therefore combines bundler externalization with an exact runtime dependency.

- The emitted `dist/index.js` no longer contains the native addon. A bundle-only artifact copied without installed dependencies will fail at import.
- Version is held at `5.0.4` for Node compatibility; upgrading to 6/7 was deliberately not attempted. Native-prebuild integrity remains an accepted residual from T-103a.
